# v0.7.5 release notes

Status: **released 2026-11-20**.

## Highlights

- **Geography correctness**: the production Magento instance ignores a filter
  group that contains two conditions on the same field. `magento.orders.geography`
  now puts the `created_at` lower and upper bounds in separate ANDed groups, so
  windows are actually filtered (a one-day window returned 27 orders instead of
  the full 83,428), and uses page size 500 to cut request count.
- The surface exposes **110 tools** (about 98 Magento).

## Breaking changes

None.

## Upgrade from v0.7.4

No migration or configuration change is required; replace the image and restart
the server and worker.

## Verification checklist

- CI required gates, integration, docker, and the `e2e` job are green on the
  tagged commit.
- Release artifacts: 17/17 checksums match asset digests, cosign bundles and SBOM
  present, multi-arch image published.
- A 30-day production report is generated from 3-day slices, each under the scan
  cap, and the sample/full-coverage status is recorded.

## Known limitations

- Each call still scans at most 10,000 orders; wider windows must be sliced.
