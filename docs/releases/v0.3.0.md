# v0.3.0 release notes

Status: **released 2026-11-19**.

## Highlights

- **Media reads**: `magento.product.media.get` returns one gallery entry (file,
  label, position, types, disabled).
- **Order summary**: `magento.order.summary` exposes the design-catalog name for
  the daily order/revenue aggregation already available as `magento.sales.summary`.
- **Bulk product links**: `magento.product.links.bulk` adds or removes one link
  type for up to 50 targets with a per-target partial-success report.
- **Bulk attribute options**: `magento.attributes.options.bulk_create` adds up to
  50 option labels with a per-label partial-success report, which speeds up
  configurable variant setup.
- **Documentation**: verified against Magento's `ConfigurableProduct` webapi
  routes that no configurable media association endpoint exists (variant images
  belong on the child SKU), and added a limits/pagination table for the whole
  Magento surface.

## Breaking changes

None.

## Upgrade from v0.2.0

No migration or configuration change is required; replace the image and restart
the server and worker.

## Verification checklist

- CI required gates, integration, docker, and the `e2e` job are green on the
  tagged commit.
- Release artifacts: 17/17 checksums match asset digests, cosign bundles and SBOM
  present, multi-arch image published.
- Post-deploy: `platform.info` reports the new version; one media read succeeds
  against a test store.

## Known limitations

- Variant images are managed per child SKU (Magento has no association endpoint).
- Bulk operations are partial-success and never roll back earlier changes.
- Import batch history is pruned after 30 days.
