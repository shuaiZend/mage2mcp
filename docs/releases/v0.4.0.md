# v0.4.0 release notes

Status: **released 2026-11-19**.

## Highlights

- **Configurable lifecycle**: `magento.configurable.update` (parent fields,
  SEO/pricing, assignments) and `magento.configurable.create_variations`
  (explicit SKU/attribute children created, linked, and skipped when present).
- **Document emails**: `magento.invoice.email`, `magento.shipment.email`, and
  `magento.creditmemo.email`. The recipient is always the order's customer; the
  gateway never accepts an address.
- **MSI management**: `magento.inventory.source_create`,
  `magento.inventory.stock_source_link`, and
  `magento.inventory.stock_source_unlink` complete the source lifecycle next to
  assign/unassign/transfer.
- The surface now exposes **101 tools** (about 81 Magento).

## Breaking changes

None.

## Upgrade from v0.3.0

No migration or configuration change is required; replace the image and restart
the server and worker.

## Verification checklist

- CI required gates, integration, docker, and the `e2e` job are green on the
  tagged commit.
- Release artifacts: 17/17 checksums match asset digests, cosign bundles and SBOM
  present, multi-arch image published.
- Post-deploy: `platform.info` reports the new version; `tools/list` includes the
  new configurable and MSI tools.

## Known limitations

- `configurable.create_variations` takes explicit SKU/attribute pairs; it does
  not generate a Cartesian matrix.
- Document emails go to the order's customer only.
- Storefront GraphQL verification of variants is not implemented.
