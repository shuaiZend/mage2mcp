# v0.7.3 release notes

Status: **released 2026-11-20**.

## Highlights

- **Order geography**: `magento.orders.geography` aggregates orders in a window
  by shipping country, returning country codes, order counts, and revenue. Only
  aggregates are returned; address details and customer PII never leave Magento.
  The scan is bounded at 10,000 orders with an explicit truncation flag.
- The surface exposes **110 tools** (about 98 Magento).

## Breaking changes

None.

## Upgrade from v0.7.2

No migration or configuration change is required; replace the image and restart
the server and worker.

## Verification checklist

- CI required gates, integration, docker, and the `e2e` job are green on the
  tagged commit.
- Release artifacts: 17/17 checksums match asset digests, cosign bundles and SBOM
  present, multi-arch image published.
- Read-only acceptance against the live instance includes the new geography tool.

## Known limitations

- Orders without a shipping assignment are grouped under `UNKNOWN`.
- The aggregate reads at most 10,000 orders per call; widen the window or raise
  `max_orders` only within that bound.
