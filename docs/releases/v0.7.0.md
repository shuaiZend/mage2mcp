# v0.7.0 release notes

Status: **released 2026-11-20**.

## Highlights

- **Custom option lifecycle**: `magento.product.options` (read),
  `magento.product.options.create`, `.update`, and `.delete` cover Magento custom
  options end to end. Selectable types require 1-50 values with fixed or percent
  pricing; deletion is destructive and confirmation-gated.
- The surface exposes **107 tools** (about 95 Magento).

## Breaking changes

None.

## Upgrade from v0.6.0

No migration or configuration change is required; replace the image and restart
the server and worker.

## Verification checklist

- CI required gates, integration, docker, and the `e2e` job are green on the
  tagged commit.
- Release artifacts: 17/17 checksums match asset digests, cosign bundles and SBOM
  present, multi-arch image published.
- Post-deploy: `platform.info` reports the new version; `tools/list` includes the
  custom-option update/delete tools.

## Known limitations

- Custom option values are replaced as a set on update; partial value edits are
  not supported.
- Storefront verification of variants is not planned (ADR-0022).
