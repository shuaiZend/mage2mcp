# v0.9.0 release notes

Status: **released 2026-11-20**.

## Highlights

- **Write verification fixes (W1–W6, W9, W11, W12)** against the standard Magento
  demo:
  - media upload and attribute-option create accept Magento's scalar ids and no
    longer report failure after a successful write;
  - media update sends a complete entry (`media_type`, `file`) and accepts the
    boolean acknowledgement;
  - upstream 400/422 messages are surfaced as `details.upstream_message`
    (sanitized, ≤300 runes) and included in import row errors;
  - a missing place-order route returns `unsupported_capability` with the stage,
    cart id, and a best-effort cart cleanup;
  - missing customer-address routes return `unsupported_capability` with guidance;
  - `category.create` accepts `url_key` (sent via `custom_attributes`);
  - `inventory.assign` defaults `status` to 1 when omitted;
  - minimal CSV imports succeed.
- **Documentation**: the Magento integration guide now documents bearer-first
  authentication (OAuth 1.0a is rejected by Magento 2.4.7 demos); the write
  verification report records the fix status per defect.

## Breaking changes

- `magento.category.tree` returns its list under `categories` instead of `roots`.
  Update clients that read the old key. (Pre-1.0 output rename.)

## Upgrade from v0.8.1

No migration or configuration change is required; replace the image and restart
the server and worker.

## Verification checklist

- CI required gates, integration, docker, and the `e2e` job are green on the
  tagged commit.
- Release artifacts: 17/17 checksums match asset digests, cosign bundles and SBOM
  present, multi-arch image published.
- The fixed binary was re-verified against the demo: media upload/update,
  attribute-option create, category create with `url_key`, inventory assign
  without `status`, minimal import, and the unsupported-route errors all behave
  as documented.

## Known limitations

- Automatic admin-token acquisition/refresh (W7) is not implemented.
- The demo does not expose cart place-order or customer-address routes, so those
  tools return `unsupported_capability` there.
- G3 (GA4 conversion data), G10 (catalog-drift snapshot), G11 (scale), and G13
  (guest-checkout measurement) remain open from the analytics gap list.
