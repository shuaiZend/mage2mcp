# v0.7.6 release notes

Status: **released 2026-11-20**.

## Highlights

- **Business analysis**: `magento.sales.analysis` aggregates an order window into
  orders, revenue, AOV, discounts, shipping, tax, guest share, refunds, a daily
  trend, status/payment/store/currency mix, shipping country, and top SKUs.
  Configurable child rows are excluded so revenue and quantity are not
  double-counted. Only aggregates are returned; customer PII never enters the
  result.
- The surface exposes **111 tools** (about 99 Magento).

## Breaking changes

None.

## Upgrade from v0.7.5

No migration or configuration change is required; replace the image and restart
the server and worker.

## Verification checklist

- CI required gates, integration, docker, and the `e2e` job are green on the
  tagged commit.
- Release artifacts: 17/17 checksums match asset digests, cosign bundles and SBOM
  present, multi-arch image published.
- A 30-day production business report is generated from the released image with
  writes disabled.

## Known limitations

- Revenue is `grand_total` as stored; multi-currency windows are not FX-normalized.
- Refunds are read from order item `amount_refunded`/`qty_refunded`.
