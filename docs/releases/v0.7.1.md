# v0.7.1 release notes

Status: **released 2026-11-20**.

## Highlights

- **Production read fixes**: read-only acceptance against a live Magento instance
  found four endpoint differences, now handled without changing the tool
  contract:
  - tier prices fall back to the product resource's `tier_prices`;
  - product links fall back to `product_links`;
  - order status history accepts the `items` envelope;
  - invoice/shipment/credit-memo lists use the collection endpoints with an
    `order_id` filter instead of the non-existent `/orders/{id}/...` routes.
- **Reference reads**: `magento.customer.groups` and `magento.tax.classes`
  expose the ids that customer and product writes accept.
- The surface exposes **109 tools** (about 97 Magento).

## Breaking changes

None.

## Upgrade from v0.7.0

No migration or configuration change is required; replace the image and restart
the server and worker.

## Verification checklist

- CI required gates, integration, docker, and the `e2e` job are green on the
  tagged commit.
- Release artifacts: 17/17 checksums match asset digests, cosign bundles and SBOM
  present, multi-arch image published.
- Read-only acceptance against the live instance passes with writes disabled
  (see `docs/operations/production-acceptance.md`).

## Known limitations

- Endpoint availability varies by Magento build; the fallbacks cover the
  variants observed so far.
- Tool argument-validation errors are text-only; a structured error envelope for
  every tool remains a future improvement.
