# v0.5.0 release notes

Status: **released 2026-11-20**.

## Highlights

- **`magento.configurable.set_options`**: declares the variant attributes and
  value ordering of an existing configurable parent (1-10 options, one save per
  option).
- **Interface convergence**: the tool catalog now maps 11 design names to their
  implemented equivalents, marks 3 tools as **not planned** with reasons, and
  separates the remaining roadmap names. ADR-0022 records the REST-admin scope
  decision (no storefront GraphQL, no Magento plugin, no direct database).
- The surface exposes **102 tools** (about 82 Magento).

## Breaking changes

None.

## Upgrade from v0.4.0

No migration or configuration change is required; replace the image and restart
the server and worker.

## Verification checklist

- CI required gates, integration, docker, and the `e2e` job are green on the
  tagged commit.
- Release artifacts: 17/17 checksums match asset digests, cosign bundles and SBOM
  present, multi-arch image published.
- Post-deploy: `platform.info` reports the new version and `tools/list` includes
  `magento.configurable.set_options`.

## Known limitations

- Storefront verification of variants is not planned (ADR-0022).
- Cloudflare breakdowns, GA4 acquisition/funnel reports, and unified funnels
  remain roadmap items.
