# v0.7.2 release notes

Status: **released 2026-11-20**.

## Highlights

- **Reference read fix**: the v0.7.1 read-only verification against the live
  instance showed that `/customerGroups` and `/taxClasses` do not exist. Magento
  exposes both as search collections, so `magento.customer.groups` and
  `magento.tax.classes` now call `/customerGroups/search` and
  `/taxClasses/search` and decode the `items` envelope.
- The surface exposes **109 tools** (about 97 Magento).

## Breaking changes

None.

## Upgrade from v0.7.1

No migration or configuration change is required; replace the image and restart
the server and worker.

## Verification checklist

- CI required gates, integration, docker, and the `e2e` job are green on the
  tagged commit.
- Release artifacts: 17/17 checksums match asset digests, cosign bundles and SBOM
  present, multi-arch image published.
- Read-only acceptance against the live instance passes with writes disabled,
  including both reference reads (see `docs/operations/production-acceptance.md`).

## Known limitations

- Endpoint availability varies by Magento build; the fallbacks cover the variants
  observed so far.
- Tool argument-validation errors are text-only.
