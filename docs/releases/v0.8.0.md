# v0.8.0 release notes

Status: **released 2026-11-20**.

## Highlights

- **Business analysis fixes (G1, G2, G4–G9)** from the production drill-down:
  - product projection carries `category_ids` and `website_ids`;
  - `magento.sales.analysis` adds repeat/new customer splits, normalized coupons,
    shipping-method mix, AOV bands, weekday/hour buckets in the store timezone,
    refunds by SKU, shipment latency and unshipped orders, a mixed-currency flag,
    and per-currency AOV;
  - store labels are normalized.
- **New reads**: `magento.store.configs` (locale, currencies, timezone) and
  `magento.categories.flat` (id/parent/name/level/path).
- The surface exposes **113 tools** (about 101 Magento).

## Breaking changes

None; new fields and tools are additive.

## Upgrade from v0.7.6

No migration or configuration change is required; replace the image and restart
the server and worker.

## Verification checklist

- CI required gates, integration, docker, and the `e2e` job are green on the
  tagged commit.
- Release artifacts: 17/17 checksums match asset digests, cosign bundles and SBOM
  present, multi-arch image published.
- A read-only production run of `magento.sales.analysis` returns the new
  dimensions (repeat/coupon/latency/timezone) for the 30-day window.

## Known limitations

- G3 (GA4 conversion data), G10 (catalog-drift snapshot), G11 (scale), G12
  (structured error envelope), and G13 (guest-checkout measurement) remain open.
