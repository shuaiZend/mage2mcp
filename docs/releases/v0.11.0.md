# v0.11.0 release notes

Status: **released 2026-11-20**.

## Highlights

- **Write-safety guidance**: a new `write_safety` MCP prompt and expanded write-tool
  descriptions warn that creating/moving/deleting categories, creating/deleting
  attributes or options, and changing `url_key` can alter product URL structure and
  break links. `docs/write-safety.md` documents the checklist and approval rules.
- **Product-copy defect fixes (D1–D3, D5, D6, D8–D11)**:
  - `product.options.create` falls back to the product-save path when the option
    route is missing, and reports both failures with their messages;
  - `weight` is sent as a top-level product field and no longer silently dropped;
  - `configurable.create` sets the parent stock status after linking and reports
    `parent_in_stock`;
  - product reads include description, short description, `url_key`, meta fields,
    weight, and custom attributes;
  - `configurable.children` exposes each child's variant attributes and accepts
    `sku` as an alias;
  - children and variations accept an optional `name`;
  - optional SEO checks (meta_keywords) no longer lower the score.

## Breaking changes

None; new response fields are additive.

## Upgrade from v0.10.0

No migration or configuration change is required.

## Verification checklist

- CI required gates, integration, docker, and the `e2e` job are green on the
  tagged commit.
- Release artifacts: 17/17 checksums match asset digests, cosign bundles and SBOM
  present, multi-arch image published.
- Live demo verification: `weight` persisted, product detail fields returned,
  `parent_in_stock: true`, child names/attributes returned, `sku` alias works,
  and the custom-option fallback reports both route failures.

## Known limitations

- The demo rejects custom-option creation through both the option route and the
  product-save fallback (`The ProductSku is empty`); the tool reports
  `unsupported_capability` with both statuses. Other Magento builds may accept the
  fallback.
- `meta_keywords` is absent on Magento 2.4.7; the audit treats it as optional.
