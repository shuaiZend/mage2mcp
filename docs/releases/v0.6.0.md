# v0.6.0 release notes

Status: **released 2026-11-20**.

## Highlights

- **Tool contract tests**: the 90+ Magento tool names are pinned in
  `testdata/tool-names.txt`, and `docs/implemented-tools.md` is checked against
  the registry, so an accidental rename or doc drift fails CI.
- **`magento.product.options`**: reads custom options (not variant options) with
  each value's price and price type.
- **`magento.product.media.types`**: lists the media roles available for an
  attribute set, so uploads use valid type codes.
- The surface exposes **104 tools** (about 92 Magento).

## Breaking changes

None.

## Upgrade from v0.5.0

No migration or configuration change is required; replace the image and restart
the server and worker.

## Verification checklist

- CI required gates, integration, docker, and the `e2e` job are green on the
  tagged commit.
- Release artifacts: 17/17 checksums match asset digests, cosign bundles and SBOM
  present, multi-arch image published.
- Post-deploy: `platform.info` reports the new version; `tools/list` includes the
  new option and media-type tools.

## Known limitations

- Custom options are read-only; creating or editing them is not implemented.
- Storefront verification of variants is not planned (ADR-0022).
