# v0.8.1 release notes

Status: **released 2026-11-20**.

## Highlights

- **Structured tool errors (G12)**: every tool now returns a machine-readable
  envelope in `structuredContent` for failures —
  `{"code": "...", "message": "...", "details": {...}, "retryable": ...}` — and
  `invalid_argument` for schema-validation failures. Agents no longer have to
  parse error text to branch on the taxonomy.
- **Documentation refresh**: README (English and Chinese) now reflects v0.8.x
  (112 tools, tool surface by module, architecture, production validation);
  the conformance matrix records the structured-error contract; the gap list
  marks G12 fixed.

## Breaking changes

None; the text content of tool errors is unchanged, and `structuredContent` is
additive.

## Upgrade from v0.8.0

No migration or configuration change is required; replace the image and restart
the server and worker.

## Verification checklist

- CI required gates, integration, docker, and the `e2e` job are green on the
  tagged commit.
- Release artifacts: 17/17 checksums match asset digests, cosign bundles and SBOM
  present, multi-arch image published.
- A read-only production call with invalid arguments returns
  `structuredContent.code = invalid_argument`.

## Known limitations

- G3 (GA4 conversion data), G10 (catalog-drift snapshot), G11 (scale), and G13
  (guest-checkout measurement) remain open.
